Definition

Statistics is the science which deals with the

  1. Collection of data
  2. Organization of data or classification of data
  3. Presentation of data
  4. Analysis of data
  5. Interpretation of data

Scope and importance

Functions of statistics: Statistics plays a crucial role in simplifying complex data, transforming it into clear and meaningful information.

It supports decision-making by presenting facts in an organized manner, aids in the formulation of effective policies, facilitates comparisons, and assists in making forecasts.

By applying appropriate statistical methods, researchers can draw valid conclusions from experiments.

Branches of statistics

Statistics
Descriptive statistics, which deals with summarizing data from a sample or a population using indexes or measures such as the mean or standard deviation etc.
Inferential statistics, use a random sample of data taken from a population to describe and make inferences about the population parameters.

Population and sample

Population

A population is the complete group of interest

Sample

a sample is a part selected for study.

A parameter describes a population, while a statistic is calculated from sample observations.

Types of variables

TypeFrom the textbook
QuantitativeA quantitative variable is one that can be expressed in numerical terms and takes values that are measurable.
DiscreteDiscrete variables are variables that can only take a finite or countable number of distinct values.
ContinuousContinuous variables, on the other hand, are variables that can take any value within a given range or interval and can be measured.
CategoricalCategorical variables classify observations into groups.

Collection of data

Primary data

Primary data are first-hand, original data collected directly from a single source by the researcher for a specific purpose.

Secondary data

In contrast, secondary data are obtained from existing sources or agencies and have been previously collected and processed for different purposes.

Measurement scales

NominalData measured on the nominal scale consist of categories that are distinct but have no inherent order or ranking.
OrdinalThis means that the categories have a specific rank or order, but the differences between the categories are not necessarily uniform or meaningful.
IntervalOn the interval scale, the data points are ordered, and the differences between them are meaningful and measurable.
RatioThe ratio scale is the highest level of measurement and applies to quantitative data.

Constructing a grouped distribution

  1. Decide the number of classes you wish to construct
  2. Determine the class width
  3. Set up the individual class limits
  4. Tally the items into the classes
  5. Count the number of items in each class

Important formulae

Number of classes using Sturges' formula$$k = 1 + 3.322\log_{10}N$$
Approximate class width$$C = \frac{|\max-\min|}{k}$$
Class mark$$\text{Class mark} = \frac{\text{Lower class limit}+\text{Upper class limit}}{2}$$
Class width$$C = \text{Upper class boundary}-\text{Lower class boundary}$$
Relative frequency$$\text{Relative frequency} = \frac{f}{N}$$
Sum of frequencies$$\sum f = N$$

Key points and limits

Common limitations of statistics: Statistical conclusions depend on the quality of the data, the design of the study and the assumptions of the method.

A large dataset cannot by itself correct biased selection or poor measurement.

Sample results are subject to uncertainty, and an association alone does not establish cause and effect.
