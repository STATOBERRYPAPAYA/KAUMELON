1Distributions & expectation

Discrete

p.m.f. $p(x) = P(X = x)$; $p(x) \ge 0$, $\sum p(x) = 1$

Continuous

p.d.f. $f(x)$; probability = area under the curve; total area = 1
Expected value (discrete)$$E(X) = \sum x\,p(x)$$
Expected value (continuous)$$E(X) = \int x f(x)\,dx$$

Expected value = the long-run average of the random variable.

2Bernoulli

A single trial with two outcomes: success (1), failure (0). Parameter $p$.

p.m.f.$$p(x) = p^x (1-p)^{1-x},\quad x = 0, 1$$
Mean$p$Variance$p(1-p)$

3Binomial $B(n, p)$

Number of successes in $n$ fixed, independent Bernoulli trials with constant success probability $p$; $q = 1 - p$.

p.m.f.$$p(x) = \binom{n}{x} p^x q^{n-x}$$
Mean · Variance$$E(X) = np,\quad Var(X) = npq$$
Fitting: estimate $p$$$\hat{p} = \frac{\bar{x}}{n}$$

Variance < mean. Expected frequency = $N \times p(x)$, $x = 0, 1, \ldots, n$.

4Poisson $P(\lambda)$

Counts of events (0, 1, 2, …) at a rate; approximates rare binomial successes.

p.m.f.$$p(x) = \frac{e^{-\lambda}\lambda^x}{x!}$$

Mean = Variance = $\lambda$. Fit with $\hat\lambda = \bar{x}$.

5Normal $N(\mu, \sigma^2)$

p.d.f.$$f(x) = \frac{1}{\sigma\sqrt{2\pi}}\, e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$
  • Continuous, bell-shaped, symmetric about $\mu$; mean = median = mode
  • Skewness 0, kurtosis $\beta_2 = 3$; odd central moments are zero
  • Tails approach the x-axis but never touch it
  • Q.D. ≈ 0.6745σ; M.D. ≈ 0.7979σ

!Common mistakes

  • Binomial needs a fixed $n$ and constant $p$.
  • $P(X = x) = 0$ for continuous variables: use intervals.
  • Forgetting $1 -$ table value for upper-tail areas.
