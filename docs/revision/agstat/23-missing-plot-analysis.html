Missing Plot Analysis

Handling a lost observation in CRD, RCBD and Latin square: direct fitting, Bartlett's covariance method and substitution.
5-minute revision
Authors: Dr. Pratheesh P. Gopinath · Dr. Adarsh V.S. · Mohammed Hisham M. · Dr. Manju Mary Paul

1Why plots go missing

Animal or pest damage, flooding, theft, recording errors… Always record why an observation is missing.

A poor result caused by a treatment is real data and must not be discarded.

A missing plot destroys the balance of an RCBD or Latin square; a CRD copes directly.

2CRD: fit directly

Analyse the observed responses with unequal treatment sample sizes (no substitution needed).

Error df$$edf = n_{obs} - v$$
SE of a difference$$SE = \sqrt{MSE\left(\frac{1}{n_i} + \frac{1}{n_j}\right)}$$

3RCBD: one missing value

Substitution estimate$$\hat{x} = \frac{rB + vT - G}{(r-1)(v-1)}$$

$B$, $T$ = observed totals of the affected block and treatment; $G$ = observed grand total (all excluding the missing value).

Error df$$(r-1)(v-1) - 1$$

4Latin square: one missing value

Substitution estimate$$\hat{x} = \frac{v(R + C + T) - 2G}{(v-1)(v-2)}$$

$R$, $C$, $T$ = observed totals of the affected row, column and treatment; $G$ = observed grand total.

Error df$$(v-1)(v-2) - 1$$

5Bartlett's covariance method

Create an imaginary covariate $X$: 1 (or −1) for the missing plot, 0 elsewhere. Set $Y = 0$ for the missing plot. Then run ANCOVA for the design.

The indicator accounts for the missing position: total and error df are each one less than in the complete design.

6After substituting

  • The estimate minimises the error SS.
  • Subtract one error df per estimated value.
  • The treatment SS can be inflated: apply the bias correction.
  • Comparisons involving the affected treatment need adjusted SEs.
  • Several missing values: estimate by iteration.

7Choosing an approach

DesignApproachError df
CRDFit observed data (unequal $n_i$)$n_{obs} - v$
RCBDSubstitution $\hat x$, Bartlett's method, or fit the observed data$(r-1)(v-1) - 1$
Latin squareSubstitution $\hat x$ or Bartlett's method$(v-1)(v-2) - 1$

!Common mistakes

  • Counting $\hat x$ as a real observation.
  • Including the missing cell in $B$, $T$ or $G$.
  • Ignoring missingness linked to the response itself (bias).
